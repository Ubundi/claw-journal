## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them to the maintainers privately. You can do this by sending an email to the maintainers or by using GitHub's private vulnerability reporting feature if enabled for this repository.

We will try to acknowledge receipt of your vulnerability report within 48 hours and will strive to send you regular updates about our progress. If a fix is necessary, we will work with you to coordinate a public disclosure.
