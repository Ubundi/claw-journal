# Maintainer Actions Needed

1. Add your community URL (Discord/Slack) into the Community section of the README.
2. Add "good first issue" labels to 3-5 easy issues on GitHub.
3. Create a Discord community channel.
4. Write a dev.to launch post.
5. Post to r/opensource, r/programming.
6. Submit to Hacker News ("Show HN").
7. Tweet thread about the problem it solves.
8. Consider Product Hunt launch.
